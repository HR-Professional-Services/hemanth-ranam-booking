# SECURITY & PRIVACY POLICY — HR BOOKINGS

* **Anti-Collisions**: ACID-compliant transactional reservation logic prevents concurrent double-bookings.
* **Customer Data Privacy**: Customer phone numbers and emails are protected and never shared with third parties.
* **Prepared SQL Bindings**: Parameterized queries eliminate SQL injection risks.
* **Origin CORS Protection**: Enforced browser API origin verification.
* **Backup Guarantee**: Point-in-time SQLite snapshot automation.
